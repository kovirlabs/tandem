# M2 Voice Implementation Plan

> **For agentic workers:** Built by three parallel agents (input, output, UI) on disjoint files. Steps use checkbox (`- [ ]`) syntax. Don't commit unless the user asks (the repo has no commits yet).

**Goal:** Let the user talk to the companion and hear it reply. Part A is push-to-talk with local speech-to-text, Part B is local Piper voices with sentence-streamed speech and lip sync, and Part C is hands-free listening with barge-in and an optional wake phrase.

**Architecture:** All audio logic lives in `core/src/audio/` in the Rust core. The mic feeds the input controller, which turns speech into text with whisper.cpp and sends it to `Core::send_message(text, Via::Voice)`. Chat events pass through `SpeechTap` to the `SpeakerPipeline`, which splits the reply into sentences, synthesizes them with Piper, plays them, and emits mouth levels. The UI only sends commands and renders the `voice://*` events.

**Tech Stack:** Rust (cpal, whisper-rs, ort/Silero VAD, Piper, rodio or cpal output), Tauri 2 (global-shortcut plugin), React/Zustand.

**Spec:** `docs/SPEC.md` §3.3, §3.4 (mouth), §5.4 (voice turn pipeline), §6.2–6.3, §7 (latency). Rules in `CLAUDE.md`.

## Global Constraints
- License is GPL-3.0-or-later (ADR 0003). Every new dependency must be GPL-3-compatible. Record each voice model's license from its model card. Never offer non-commercial (NC) voices by default.
- Audio never touches disk or logs. `AudioClip` stays in memory, and there is no "save recording" debug option (rules 1 and 9 in spirit).
- Any STT or TTS call to a non-local provider must pass `router::privacy::check(Modality::Audio, locality, consent)`. M2 ships local-only engines, but adapters must still report `locality()` honestly.
- No network calls the user didn't start (rule 10). A model or voice downloads only when the user presses Download in Settings, and the button names the host (huggingface.co) first.
- Companion name is never hard-coded. The wake phrase is "Hey {companion_name}" and comes from `profile.companion.name`.
- No shame language in any copy. For example, use "I didn't catch that. Want to try again?" and never "You didn't speak clearly."
- Voice labels must never include gender or ethnicity words. Voice is never auto-paired with appearance.
- Caption all speech. Every spoken reply also appears in the chat panel, which already happens via `chat://message`.
- Latency target: under 2.5 s from end of speech to first audio with local models (SPEC §7). Synthesize sentence 1 while the LLM is still streaming.
- No `unwrap()` outside tests. Use `thiserror` (`AudioError`). Run heavy blocking work (whisper, piper) in `tokio::task::spawn_blocking`.
- Constructors must not open audio devices. `cargo test -p core` must pass on CI machines with no mic, speaker or models. Tests needing real models or devices are `#[ignore]`.

## Review Focus
1. **PTT pressed while the companion is talking.** Speech stops at once (≤100 ms), the queue is dropped, and the character leaves `talking`. No overlapping audio. *(Input: `ptt_start_stops_speaker`; Output: `stop_clears_queue_and_overlay`.)*
2. **A tap that's too short, or only silence.** Under 0.3 s, or an empty or hallucinated transcript (`[BLANK_AUDIO]`, `(music)`, "Thank you." on silence). Nothing is sent, the phase returns to `Ready`, and problem = `voice.not_heard`. *(Input: `short_clip_sends_nothing`, `hallucination_filtered`.)*
3. **No mic, or mic permission denied.** The status problem is `voice.error.no_mic` / `voice.error.mic_denied`, text chat keeps working, and nothing panics. *(Input: `device_error_maps_to_problem` with a fake source.)*
4. **Models not downloaded.** Phase is `Off` with problem `voice.error.stt_missing` / `voice.error.voice_missing`, and nothing downloads on its own. *(Input and Output tests: `missing_model_reports_problem`. UI test: no download call without a click.)*
5. **Repeated or out-of-order commands.** For example `ptt_stop` without `ptt_start`, a double `ptt_start`, or a settings change mid-utterance. These must be idempotent and leave no stuck phase. *(Input: `stop_without_start_is_ok`, `double_start_is_ok`.)*

## Lane 1 — Input (Parts A + C)

### Task I1: Mic capture (Part A)
**Files:** `core/src/audio/capture.rs`
**Interfaces produced (internal to lane):**
- `trait MicSource: Send + Sync { fn start(&self, on_frame: Box<dyn Fn(&[f32]) + Send>) -> Result<(), AudioError>; fn stop(&self); fn devices(&self) -> Vec<String>; }`
- `CpalMic::new(device_name: Option<String>)`: opens the device lazily in `start`. Converts to mono and resamples to `STT_SAMPLE_RATE` (16 kHz) before calling `on_frame`.
- `fn rms_level(frame: &[f32]) -> f32`, 0–1, used for the mic meter `AudioLevel { source: Mic }` at about 30 Hz.
- `FakeMic` (cfg test) feeds scripted frames or returns scripted errors.
- [ ] Tests: `resample_48k_to_16k_length` (48 000 samples in → 16 000 ±1 out), `stereo_downmix_averages`, `rms_of_silence_is_zero`, `rms_of_full_scale_sine_is_about_0_7`.
- [ ] Map the cpal permission error to `AudioError::PermissionDenied`, and no device to `NoInputDevice`.

### Task I2: whisper.cpp STT (Part A)
**Files:** `core/src/audio/stt.rs`, Cargo section (`whisper-rs` with the `metal` feature on macOS).
**Interfaces:**
- `pub fn stt_model_file(id: &str) -> Option<ModelFile>` for `tiny.en`, `base.en`, `small.en`. URL `https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-{id}.bin`, rel_path `whisper/ggml-{id}.bin`. Add the sha256 if published.
- `WhisperStt::load(path) -> Result<Self, AudioError>` implements `SttProvider` with `locality() == Local`. Transcribes in `spawn_blocking`, language `en`, no timestamps.
- `pub fn clean_transcript(raw: &str) -> String` trims the text and returns `""` for hallucination tokens (`[BLANK_AUDIO]`, `(music)`, `[Music]`, `(silence)`, a lone "Thank you." / "Thanks for watching!").
- [ ] Tests: `hallucination_filtered` (each token → `""`), `real_text_kept`, `model_file_urls`. Add `#[ignore] whisper_transcribes_fixture`, which generates speech in memory or skips if no model is present. It never writes a file.

### Task I3: Controller + push-to-talk (Part A)
**Files:** `core/src/audio/controller.rs` (fill in the stubbed API, keeping the signatures).
**Behavior:**
- `ptt_start`: if voice is disabled, return `Err(AudioError::Disabled)`. Otherwise call `speaker.stop()`, start the mic, set phase `Listening`, stream the mic level, and buffer frames (cap 60 s).
- `ptt_stop`: stop the mic. Under 0.3 s → `Ready` with problem `voice.not_heard`, return `""`. Otherwise go to `Transcribing` → `clean_transcript`. Empty → same as above. Non-empty → `speaker.arm_next_reply()`, phase `Thinking`, spawn `core.send_message(text, Via::Voice)` through the `Weak<Core>`, and return the transcript.
- Speaking phase: after a send, a watcher task checks `speaker.is_speaking()` every 100 ms. It sets phase `Speaking` while true and `Ready` once the reply is finished and the speaker is idle (or after 30 s with no speech).
- `apply_settings`: reloads the whisper model if `stt_model` changed (lazily, on the next use), stores the companion name for I5, and starts or stops hands-free.
- `status()`: `stt_ready` = model present, `tts_ready` = `speaker.ready()`. The phase is `Off` when disabled or when the model is missing.
- `download_stt_model(id)`: `models::ensure(...)`, emitting `CoreEvent::Download`.
- Every phase change emits `CoreEvent::Voice(status)`.
- [ ] Tests (fake mic, fake STT, fake speaker, `CollectingSink`): `ptt_start_stops_speaker`, `short_clip_sends_nothing`, `stop_without_start_is_ok`, `double_start_is_ok`, `disabled_returns_error`, `missing_model_reports_problem`, `transcript_is_sent_as_voice_turn` (use `Core::with_store` + the mock provider and check that a `ChatMessage` with `via == Voice` appears), and `device_error_maps_to_problem`.
- [ ] `audio_never_written_to_disk`: run a full fake PTT turn with `TMPDIR` pointed at a fresh temp dir, then assert the models dir and the temp dir contain no new files.

### Task I4: VAD hands-free + barge-in (Part C)
**Files:** `core/src/audio/vad.rs`, `controller.rs`.
- Silero VAD v5 ONNX via `ort`. The model is fetched through `models.rs` on first enable of hands-free (`vad/silero_vad.onnx`, from the snakers4/silero-vad GitHub release, MIT). It downloads with the STT model and is listed in the same Settings download.
- `Vad::process(frame_512_samples) -> f32` speech probability. `Segmenter` takes probabilities and emits `SpeechStart` / `SpeechEnd(clip)`. Start ≥ 0.5 for 250 ms, end after 700 ms below 0.35, max 30 s.
- Hands-free loop: continuous capture → segments → the same transcribe-and-send path as PTT.
- Barge-in (when `barge_in` is on): while `speaker.is_speaking()`, speech with p ≥ 0.85 for ≥ 300 ms calls `speaker.stop()` (raised thresholds limit self-echo). Note in the Settings copy (UI lane) that headphones work best.
- [ ] Tests on `Segmenter` with scripted probabilities: `segment_starts_after_250ms`, `segment_ends_after_700ms_silence`, `blip_is_ignored`, `max_length_splits`, `barge_in_needs_300ms_high_prob`.

### Task I5: Wake phrase (Part C)
**Files:** `core/src/audio/wake.rs`, `controller.rs`.
- Wake detection works on transcripts: no extra model, and it follows renames.
- `pub fn match_wake(transcript: &str, name: &str) -> WakeMatch { None, Only, WithRest(String) }`. Ignore case and punctuation. Accept "hey"/"hi"/"okay" + name, with small edit distance on the name (≤1 for names ≤6 chars, ≤2 otherwise).
- In hands-free mode with `wake_phrase` on: `None` → drop silently. `WithRest` → send the rest. `Only` → accept the next segment without the phrase for 8 s.
- [ ] Tests: `wake_with_rest`, `wake_only_opens_window`, `renamed_companion`, `no_wake_dropped`, `fuzzy_name_one_edit`.

## Lane 2 — Output (Part B)

### Task O1: Piper engine decision + `TtsProvider`
**Files:** `core/src/audio/tts.rs`, Cargo section, optional `core/build.rs`, `docs/adr/0004-piper-integration.md`.
- Pick the in-process route and record why in ADR 0004. Options, in order of preference: (1) a maintained Rust crate wrapping Piper ONNX + espeak-ng phonemization; (2) build `libpiper` from OHF-Voice/piper1-gpl with CMake in `build.rs`; (3) `ort` + espeak-ng phonemizer directly. It must build on macOS (arm64) and Windows/Linux, with no Python and no network at build time beyond crates.io / git deps. Avoid a Tauri sidecar unless all three fail.
- `PiperTts::load(onnx_path, json_path) -> Result<Self, AudioError>` implements `TtsProvider` (`Local`) and synthesizes in `spawn_blocking`. `rate` maps to `length_scale = 1.0 / rate`.
- `pub fn voice_catalog() -> &'static [CatalogVoice]`: about 6 English voices from `https://huggingface.co/rhasspy/piper-voices/resolve/main/<lang>/<locale>/<name>/<quality>/<id>.onnx` (+ `.onnx.json`). Each entry has a license read from its MODEL_CARD. **Exclude NC licenses.** Labels have no gender words. Mark one provisional default (warm, mid-range; SPEC says a listening test makes the final pick) and say which one in the ADR.
- [ ] Tests: `catalog_has_default`, `catalog_labels_have_no_gender_words` (deny-list: male, female, man, woman, boy, girl), `catalog_excludes_nc`, `rate_maps_to_length_scale`. Add `#[ignore] piper_synthesizes_hello`.

### Task O2: Sentence splitter
**Files:** `core/src/audio/sentences.rs`
- `SentenceSplitter { push(&mut self, delta: &str) -> Vec<String>, finish(&mut self) -> Option<String> }`. Split on `.!?` + whitespace (keep "v1.2", "e.g.", "Dr."). Merge a first chunk shorter than 20 chars with the next. Strip markdown (`*`, `_`, `#`, backticks, links → their text), emoji, and any `<think>…</think>` text.
- [ ] Tests: `splits_streamed_deltas`, `keeps_decimals_and_abbrev`, `short_first_merges`, `strips_markdown_and_emoji`, `finish_flushes_tail`, `think_removed_across_deltas`.

### Task O3: Playback + mouth levels
**Files:** `core/src/audio/playback.rs`
- `trait AudioOut: Send + Sync { fn play(&self, clip: AudioClip, volume: f32, on_level: Box<dyn Fn(f32) + Send>) -> Result<(), AudioError>` (blocks until done or stopped)`; fn stop(&self); }`. Use the rodio or cpal output device, opened lazily. Levels are RMS per 33 ms window, smoothed (attack fast, release ~120 ms), 0–1.
- `FakeOut` (cfg test) records clips and simulates duration.
- [ ] Tests: `levels_follow_envelope`, `stop_interrupts_play`, `volume_scales`.

### Task O4: `SpeakerPipeline`
**Files:** `core/src/audio/speaker.rs` (fill in the stubbed API, keeping the signatures).
- `observe`: what gets spoken depends on settings. Only assistant text is spoken. Skip everything if `!enabled || mute || speak_replies == Never`. `VoiceTurns` speaks only when armed. `Always` speaks every reply. Check-ins (`ChatMessage` with `via == Checkin`) speak if `speak_checkins`. Streamed replies are spoken from `ChatDelta` as sentences complete. The final assistant `ChatMessage` flushes the tail, and if no deltas came (non-native-tool providers emit no deltas), it speaks the final text. Read `conversation/mod.rs` to match the delta and message ids.
- Worker task: a sentence queue → `TtsProvider::synthesize` (sentence n+1 synthesizes while n plays) → `AudioOut::play`. Each level becomes `CoreEvent::Level { Speaker }` via the raw sink. Set `engine.set_overlay(Some(Talking))` on the first audio and `None` when the queue drains.
- `stop()`: bump a generation counter so in-flight synthesis is discarded, clear the queue, call `AudioOut::stop`, clear the overlay, and emit level 0.
- `voices()`, `download_voice(id)` (both files via `models::ensure`, model id `piper:<id>`), `preview_voice` (ignores mute and the armed flag), and `ready()` (the selected voice's files are present).
- [ ] Tests (fake TTS + fake out + `CollectingSink`): `voice_turn_reply_is_spoken`, `typed_reply_not_spoken_by_default`, `always_speaks_typed`, `mute_speaks_nothing`, `checkin_spoken_when_enabled`, `stop_clears_queue_and_overlay`, `final_message_without_deltas_is_spoken`, `missing_model_reports_problem` (`ready()` false, nothing played), `levels_emitted_while_playing`.
